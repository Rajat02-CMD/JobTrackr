# JobTrackr

A simple and responsive job application tracker built with HTML, CSS and JavaScript.

JobTrackr helps users manage their job and internship applications from one place.

## 🚀 About

JobTrackr is a frontend-based job application management tool.

Users can add applications, update their status, search applications, filter them by status and keep their data saved using browser LocalStorage.

## ✨ Features

- Add job applications
- Edit existing applications
- Delete applications
- Track application status
- Search by company or role
- Filter applications by status
- Dashboard statistics
- Status badges
- LocalStorage data persistence
- Responsive design
- Mobile-friendly interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 💾 Data Storage

Job application data is stored in the browser using LocalStorage.

This means applications remain available even after refreshing the page.

## 📊 Dashboard

The dashboard provides quick statistics for:

- Total Applications
- Interviews
- Selected
- Rejected
